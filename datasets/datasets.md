# Datasets

Full annotated list with sources and use cases: [README.md → Datasets](../README.md#datasets)

1. **CiteCheck Physics Citation Benchmark** — 982 real physics citations + controlled corruptions
   ([arXiv:2605.27700](https://arxiv.org/abs/2605.27700))
2. **CiteAudit Dataset** — large-scale, human-validated, multi-domain hallucinated citation dataset
   ([arXiv:2602.23452](https://arxiv.org/abs/2602.23452))
3. **HALLMARK Benchmark** — 2,525+ annotated ML-paper citations, 14 hallucination types
   ([GitHub — rpatrik96/hallmark](https://github.com/rpatrik96/hallmark))
